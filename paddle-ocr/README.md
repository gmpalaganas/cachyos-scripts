# KDE Paddle OCR
Extract text from a screenshot using Spectacle and PaddleOCR

## Requirements
- `spectacle`
- `paddle-ocr` installed via uv inside the default venv `.venv`
  - `uv pip install paddlepaddle-gpu==3.2.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/`
  - `uv pip install paddleocr[all]`

## Usage
- `./screenshot-ocr.sh`
